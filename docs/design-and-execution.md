# RentManager デザイン・AI実行方針
承認済み要件に対する追加指示（2026-09-23）。
## デザイン
- Apple製品のような抑制された見た目を参考に、白/淡いグレー、濃い文字、青の主要操作、細い境界線、控えめな影、ゆとりある余白を使用。Apple公式製品と誤認させるロゴや表示は使用しない。
- PCは左ナビと一覧中心。モバイルは折り畳みナビと読みやすいカード/詳細表示。主要文字は14〜16px程度、見出し24〜32px、余白8px系、角丸10〜16pxを起点にする。コントラスト等は非機能要件を優先。
- 写真アップロード、グラフ、通知ベル、予約、AI機能を見た目の都合で追加しない。備品には簡単なカテゴリの線画アイコンを使える。
- 貸出可能・貸出中・期限超過は色と文字で表示。主要操作は「借りる」、本人一覧では「返却」「延長」。
- GPT Imagesの完成想定図は見た目の参考。画像の文字、件数、架空UIを仕様の根拠にしない。動くUIはHTML/CSS/Reactで実装し、生成画像を画面として貼り付けない。
- デザイン・UIの設計、実装、レビューでは `apple-design` スキルの使用を必須とする。着手前に実装環境の該当SKILL.mdを読み、各画面と共通コンポーネントへ適用する。使用したスキルの取得元/パスと適用内容をPRに記録する。見つからない場合は既存スキルの場所・取得元を調べ、それでも特定できなければユーザーに場所を確認する。スキル未使用のままデザイン実装を完了扱いにしない。認証・DBなど独立した作業は継続する。
## AI実行
- 最初の環境構築から実装・検証をAI担当が行う。手順の説明だけで完了にしない。
- CLI/MCP/APIの利用可能性を確認し、必要に応じて認可されたbrowser/computer useで管理画面操作を行う。ブラウザ操作前にその環境のブラウザスキルを読む。
- ログイン、MFA、CAPTCHA、本人しか承認できない連携はユーザーへ引継ぎ、回避しない。接続は実装するエージェント側で確認する。
- 許可済みの専用無料リソース設定、環境変数、認証許可ドメイン、初期化を担当し、成功した設定と残るブロッカーを記録する。
- 有料契約への変更や他案件への変更はしない。接続できない場合でも独立作業は進めるが、未検証の外部接続を完了扱いにしない。
- 並列作業はRM-01→RM-02→RM-03の後にRM-04〜09。共有DB定義・ロックファイル・認証基盤の所有者を固定する。
